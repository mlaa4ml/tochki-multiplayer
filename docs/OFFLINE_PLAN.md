# План создания бессерверной версии игры (Offline Lab)

## Цель
Предоставить возможность запускать игру и тестировать бота локально в браузере или изолированном окружении Node.js без необходимости поднимать WebSocket-сервер.

## Архитектура
1. **Изоляция движка**:
   - Вынести всю логику из `gameEngine.js` в самодостаточный модуль, совместимый как с серверной частью, так и с браузером (через сборку или прямые ES-модули / Web Worker).
2. **Локальный контроллер партии**:
   - Написать легкий клиентский контроллер для управления состоянием матча (доска, ходы, очередь игроков, бот против бота, человек против бота).
3. **Инструменты тестирования и отладки**:
   - Интерфейс для пошаговой прокрутки партий, паузы, сохранения/загрузки логов матчей в JSON и визуализации решений бота (показывая его оценки ходов).
